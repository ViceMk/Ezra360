# Listing

Listing has a dropdown with options for views, buttons, and Linked Resources. The pointer at <mark style="color:orange;">**#1**</mark> shows how to access listing of the specific **Entity**, in this case, the Entity Name is **Accommodation**. When clicking <mark style="color:orange;">**#1**</mark> the listing shows all available items associated with it. The Listing views provide users with flexible ways to access and interact with data stored in the system.
